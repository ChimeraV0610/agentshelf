# AgentShelf

UCLA Anderson MSBA Hackathon · 选题 "When the customer is a bot"

AgentShelf 让小卖家和品牌看到"AI 购物助手眼里的自己"：用 Amazon ESCI 的真实搜索需求和一组模拟 AI 购物 agent，量化 agent 的买错率，诊断单个商品在 agent 眼里的可见度和被拒选原因，并给出经过忠实度校验的 listing 改写。

- 完整执行计划：[AgentShelf_Hackathon_Plan.md](AgentShelf_Hackathon_Plan.md)
- 数据：[amazon-science/esci-data](https://github.com/amazon-science/esci-data)（只用 `small_version==1` 且 `product_locale=='us'`）
